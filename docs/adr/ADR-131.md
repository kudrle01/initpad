# ADR-131 — Source-based SSH runtime je odstraněn, SFTP zůstává kompatibilní konektor

**Status:** Accepted

**Kontext.** Původní SSH runtime nahrával zdrojové soubory na vzdálený server,
spouštěl obecné shell příkazy a aplikacím přiděloval porty z databáze. Po
zavedení InitPad Agenta zůstal pouze jako migrační cesta. Žádné provozované
prostředí jej už nepoužívá a jeho samostatný provider, target a simulovaný VPS
zvyšují bezpečnostní i provozní složitost bez produktového přínosu. SFTP má
odlišný účel: podporuje statické a PHP aplikace na hostingu, kde nelze spustit
Agent, a proto zůstává podporovaný.

**Rozhodnutí.** Jediný podporovaný serverový runtime je Docker spravovaný
InitPad Agentem; důvěryhodná self-hosted edice může nadále používat svůj
vestavěný Docker target. SFTP zůstává omezeným publikačním konektorem pro
kompatibilní šablony, nikoli obecným SSH runtime. Odstraňuje se druh targetu
`ssh`, SSH provider, `startCommand` v manifestu šablony, portový allocator,
`Environment.allocatedPort`, simulovaný `fake-vps` a odpovídající UI.

Databázová migrace nesmí tiše osiřet běžící workload. Pokud najde prostředí
navázané přímo nebo přes allocation na SSH target, bezpečně skončí s pokynem
nejprve prostředí převázat. Nepoužívané SSH targety a allocation odstraní a až
poté zruší nevyužívaný sloupec portu.

**Důsledky.** Nabídka serverů má dvě jasné cesty: doporučený outbound Agent
pro plný lifecycle a SFTP pro omezený hosting. Control plane už nedrží obecný
vzdálený shell ani neřídí source-based procesy. Historické ADR zůstávají jako
záznam vývoje rozhodnutí; ADR-012 a ADR-095 jsou tímto rozhodnutím nahrazeny.

**Testování.** Statické a typové kontroly nesmějí najít druh targetu `ssh`,
`startCommand` ani `allocatedPort` v aktivním modelu. Provider testy nadále
ověřují Docker a SFTP. Migrační test musí doložit odmítnutí databáze s
navázaným SSH prostředím a úspěšný úklid nepoužívaného targetu.
