# ADR-156 — Aplikace odkazuje na samostatnou uživatelskou nápovědu

**Status:** Accepted

**Kontext.** Uživatelská nápověda veřejné edice vznikla jako samostatný
statický web (repozitář `initpad-docs`) a z aplikace na ni nic nevedlo. Kdo
nevěděl, jak připojit server nebo importovat repozitář, musel adresu znát.
Aplikace je dvojjazyčná (čeština a angličtina) a nápověda má být taky.

Zvažované možnosti:

- Vložit nápovědu do webové aplikace. Nápověda by se vydávala jen spolu s
  platformou a každá oprava textu by čekala na podepsaný release.
- Zapéct adresu nápovědy do obrazu webu při sestavení. Tentýž podepsaný obraz
  ale běží v SaaS i u self-hosted instalací a self-hosted edice používá Giteu,
  kterou nápověda veřejné edice nepopisuje.
- Nastavit adresu za běhu proměnnou prostředí, kterou API předá webu stejně
  jako edici. Zvoleno.

**Rozhodnutí.**

1. `INITPAD_DOCS_URL` je základní adresa nápovědy. Musí to být HTTPS adresa
   bez přihlašovacích údajů, query a fragmentu; HTTP je dovolené jen pro
   loopback při vývoji. Prázdná hodnota, výchozí v obou edicích, skryje
   všechny odkazy na nápovědu.
2. API vrací adresu jako `docsUrl` v `/auth/config`, aby ji měla i
   přihlašovací stránka, a v profilu přihlášeného uživatele vedle `edition`.
3. Nápověda je publikovaná po jazycích na `<url>/cs/` a `<url>/en/`. Kapitoly
   mají v obou jazycích stejné anglické kotvy. Web skládá odkaz
   `<url>/<jazyk>/#<kapitola>` podle aktuálního jazyka uživatele; seznam
   kapitol je typ `HelpTopic` v `apps/web/src/lib/help.ts`.
4. Odkazy se otevírají v nové kartě, aby uživatel neztratil rozpracovaný
   formulář. Obecný odkaz Nápověda je dole v levém menu. Kontextové odkazy
   Více v nápovědě jsou u obrazovek, kde se nejčastěji bloudí: Servery, Nový
   projekt, Import, Nasazení, Nastavení workspace, propojení GitHubu a
   konfigurace projektu. Přihlašovací stránka odkazuje na kapitolu Začínáme.

**Důsledky.** Nápověda se nasazuje nezávisle na platformě a provozovatel ji
zapne jednou proměnnou. Kotvy kapitol jsou veřejný kontrakt: jejich
přejmenování v nápovědě rozbije odkazy z už vydaných verzí, proto se mění jen
spolu s `HelpTopic` a nejlépe vůbec. Self-hosted instalace odkazy nemá, dokud
nepublikuje vlastní nápovědu se stejným rozložením.

**Testování.** Unit testy ověřují kontrolu `INITPAD_DOCS_URL`, složení adresy
podle jazyka a kapitoly, skrytí odkazu bez nastavené adresy a odkaz na
přihlašovací stránce.
