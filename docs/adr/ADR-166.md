# ADR-166 — Certifikát brány ke stažení s ověřitelným otiskem

**Status:** Accepted

Doplňuje [ADR-165](./ADR-165.md) a [ADR-161](./ADR-161.md).

**Kontext.** Spravovaná brána z ADR-165 vydává certifikáty aplikací vlastní
CA. Prohlížeč jí musí důvěřovat, jinak každá aplikace ukáže varování. Kořen CA
ale ležel jen na serveru Agenta v `/var/lib/initpad-gateway/ca-root.crt`; správce,
který se přihlásí do GUI z jiného počítače v síti, ho nemohl získat bez SSH.

**Rozhodnutí.**

1. Edge brány nabízí **jen veřejný kořen CA** na
   `http://<doména brány>/initpad-ca.crt` (HTTP, protože prohlížeč CA nemůže
   důvěřovat dřív, než ji získá). Každý jiný požadavek přes HTTP se
   přesměruje na HTTPS. Rewrite míří na jediný soubor, takže klíč CA ani
   konfigurace z téhož adresáře nejsou dosažitelné; je to stejný vzor jako
   u platformy (ADR-161).
2. Instalátor spočítá SHA-256 otisk kořene a předá ho Agentovi proměnnou
   `INITPAD_AGENT_GATEWAY_CA_SHA256`. Agent ho pošle platformě v dokončení
   úspěšného `gateway-preflight` (`gatewayCaSha256`); API ho uloží
   k targetu a přijme ho jen od preflightu aktuálního jobu.
3. GUI u targetu se spravovanou bránou ukáže tlačítko ke stažení, otisk ve tvaru
   `AB:CD:…` a návod pro Windows, macOS a Firefox. Stažení přes HTTP je bezpečné
   právě díky otisku, který uživatel dostane jiným, ověřeným kanálem (GUI přes
   HTTPS), a může jej porovnat se souborem.

**Důsledky.** Brána vlastní nebo veřejné CA (bez instalátoru) otisk neposílá a GUI
to řekne; odkaz zůstává. Otisk se zobrazí až po úspěšném testu brány. Nový
sloupec `Target.gatewayCaSha256` je volitelný, takže starší Agenti fungují dál.
