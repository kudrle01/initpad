# ADR-129 — Sdílený artifact fence a operation-backed lifecycle uzavírají mutační hranici

**Kontext.** GitHub ingestion už měla vlastní generační lease, ale zachycení
Gitea OCI image zapisovalo do object storu bez stejného vlastnictví. Dva shodné
CI callbacky proto mohly současně exportovat a publikovat jeden artefakt. Přímé
stop a remove na Docker/SFTP/SSH targetu navíc volaly provider mimo trvalou
`DeploymentOperation`, a stale API replika tak mohla po takeoveru zveřejnit stav.

**Rozhodnutí.** Oba zdroje buildu používají jednu komponentu
`ProjectArtifactExecutionLease`. Před sdíleným uploadem Gitea capture atomicky
rezervuje `BuildArtifact`, započítá jeho skutečnou velikost do workspace kvóty
a získá obnovovaný lease. Publikace i selhání porovnávají ownera a generaci.
Worker po ztrátě fence nesmí odstranit objekt, který už může patřit vítězné
replice. Identita commit–digest je neměnná; změna bytů pod stejným commitem
selže uzavřeně.

Přímé stop a remove nejprve atomicky získají environment lock vytvořením
`DeploymentOperation`, provider work provedou pod obnovovaným lease z ADR-126 a
výsledek publikují pouze compare-and-setem proti `activeOperationId`. Agent cesta
zůstává durable handoff do `AgentJob`; start už stejnou operation hranici používal.

**Proč.** Lokální mutex nechrání dvě API repliky a samotný stav
`ingesting/deploying` neříká, kdo smí publikovat. Jednotný databázový fence dává
každému externímu side effectu jednoho dočasného vlastníka a recovery může po
expiraci bezpečně pokračovat novou generací.

**Důsledky.** Artifact download/capture, deploy, start, stop a remove jsou
chráněné napříč API replikami. Zdrojový registry export může před rezervací
proběhnout duplicitně jako lokální read-only práce, ale pouze lease owner smí
mutovat object store a databázi. Active-active připravenost je stále nutné
potvrdit staging load testem a provozní topologií.

**Testování.** Regrese pokrývají quota reservation, immutable digest, selhání
uploadu, ztrátu Gitea capture lease bez smazání sdíleného objektu, provider
chybu stop a zákaz publikace po ztrátě deployment lease.
