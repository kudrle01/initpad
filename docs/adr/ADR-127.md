# ADR-127 — Dependency audit připouští jen úzkou a expirující výjimku

**Kontext.** Dne 2. října 2026 zveřejnil GitHub dvě nové high-severity
advisories bez opravené upstream verze. `braces` bylo v produkčním grafu pouze
proto, že build-only `tailwindcss-animate` byl chybně veden jako runtime
dependency; přesun do `devDependencies` tuto větev odstranil. Druhé advisory
`GHSA-ch52-4w7c-c8xp` zůstává přes `sigstore` a jeho klienta
`http-cache-semantics`. Nahlášený útok vyžaduje sdílenou HTTP cache a
uživatelem řízenou direktivu `max-stale`. InitPad používá knihovnu pouze pro
veřejná trust metadata v privátní per-service cache a takové vstupy
nepřeposílá. Upstream zatím nepublikoval patched release.

**Rozhodnutí.** Release gate nesnižuje auditní závažnost ani advisory globálně
neignoruje. `scripts/audit-production-dependencies.mjs` vyhodnotí JSON z
`npm audit --omit=dev`, odmítne každé neznámé zjištění a pro toto advisory
připustí pouze přesný seznam transitivních balíčků a jediný přímý root
`sigstore`. Veřejná policy obsahuje důvod a datum expirace 2. listopadu 2026.
Změna dependency řetězce, advisory identity, přímého rootu, příchod dalšího
nálezu, uplynutí termínu i odstranění nálezu bez úklidu stale výjimky gate
uzavře.

**Proč.** Automatický `npm audit fix --force` navrhuje nekompatibilní downgrade
bez odstranění kořenového problému. Časově omezené accepted risk zachovává
viditelnost a fail-closed CI, aniž by blokovalo nesouvisející změny kvůli
scénáři, jehož předpoklady v použití InitPadu neexistují.

**Důsledky.** Známé transitivní advisory je dočasně akceptované, nikoli
opravené. Nejpozději před expirací musí být nasazen opravený upstream release
nebo provedeno nové bezpečnostní rozhodnutí; veřejný SaaS nesmí přejít do
produkce s prošlou výjimkou. Běžný offline `npm run check` zůstává
deterministický, síťový `check:release` používá nový auditní gate.

**Testování.** Jednotkové testy pokrývají přesný povolený řetězec, nové
advisory, změnu direct rootu, expiraci a odstranění již nepotřebné výjimky.
Živý npm audit po oddělení build dependencies vrací pouze šest projekcí téhož
reviewed advisory a nový gate je přijme.
