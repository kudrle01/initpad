# ADR-187 — Odkazy vestavěného testovacího prostředí mimo HTTPS doménu platformy

Rozšiřuje ADR-137, ADR-173 a ADR-175.

**Status:** Accepted

**Kontext.** Vestavěné cíle stavěly odkaz na aplikaci jako
`http://<hostname z INITPAD_PUBLIC_URL>:<port>`. V režimu domény
(`https://initpad.firma.lan`) Caddy posílá pro jméno platformy hlavičku HSTS.
Prohlížeč HSTS uplatní na všechny porty daného hostu, takže odkaz
`http://initpad.firma.lan:32768` přepíše na HTTPS. Aplikace na přímém portu
mluví jen HTTP, a tak se nenačte, přestože nasazení skončilo jako běžící.
Totéž platilo pro vestavěný statický hosting na portu 8085. Režim domény
navíc nenastavoval `INITPAD_DEPLOY_BIND_ADDRESS`, takže přímé porty zůstaly
na `127.0.0.1` a z ostatních počítačů nebyly dostupné ani přes IP. Název
`Company Docker (dev/test)` neodpovídal tomu, k čemu cíl slouží.

**Rozhodnutí.**

1. Když je URL platformy HTTPS s DNS jménem a `INITPAD_DEPLOY_PUBLIC_HOST`
   není nastaven, API při startu (před seedem vestavěných cílů) přeloží jméno
   platformy na IPv4. Vestavěné aplikace i statický hosting pak dostanou
   odkaz `http://<IP>:<port>`. Uložené URL prostředí se při zobrazení
   přepisují na aktuální host, takže se opraví i dříve nasazené aplikace.
   Caddy běží na hostu InitPadu, jméno tedy vede na stejný stroj a po změně
   DHCP adresy stačí restart.
2. Loopback nebo nepřeložitelné jméno adresu nemění a API zapíše varování
   s návodem nastavit `INITPAD_DEPLOY_PUBLIC_HOST`. Explicitní hodnota má
   vždy přednost.
3. Instalátor v režimu interní sítě s DNS (`--tls internal`) při první
   konfiguraci nebo `--reconfigure` nastaví
   `INITPAD_DEPLOY_BIND_ADDRESS=0.0.0.0`, stejně jako režim IP. Veřejná
   doména bind na loopback ponechává; aplikace s HTTPS adresou nasazuje
   Agent s managed gateway.
4. Vestavěné cíle se jmenují `Test environment (Docker)` a
   `Test static hosting (SFTP)`.

**Důsledky.** Testovací prostředí funguje v interní síti s DNS bez ruční
úpravy `.env`. Kdo chce aplikace pod jménem, nastaví
`INITPAD_DEPLOY_PUBLIC_HOST` na jméno bez HSTS, nebo použije managed gateway.
Existující instalace v režimu domény získají správný odkaz po aktualizaci,
dostupnost z LAN až po `./install.sh --reconfigure` nebo ručním nastavení
bind adresy.

**Testování.** Unit testy pokrývají rozpoznání HSTS hostu, výběr adresy
(loopback, nepřeložitelné jméno, explicitní override, HTTP instalace) a
přepočet URL statického hostingu.
