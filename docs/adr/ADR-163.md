# ADR-163 — Vestavěné object storage je SeaweedFS místo MinIO

**Status:** Accepted

**Kontext.** Compose připínal poslední komunitní image MinIO z `quay.io/minio`
(ADR-099). Upstream ukončil jejich distribuci a Quay je dnes bez přihlášení
odmítá (`401 UNAUTHORIZED`, ani digest se nepodaří stáhnout), takže
`./install.sh` na čisté instalaci končí při `docker compose up`. Komunitní
MinIO navíc nedostává bezpečnostní opravy; ADR-099 ho proto držel jako
přechodnou výjimku.

**Rozhodnutí.** Služby `minio` a `minio-init` nahradily `s3` a `s3-init` nad
`chrislusf/seaweedfs:4.50` připnutým digestem. SeaweedFS je udržovaný, má
Apache-2.0 licenci a jeho S3 gateway stačí tomu, co API používá:
`HeadBucket`, `PutObject`, `HeadObject`, `GetObject`, `DeleteObject` a
presigned GET.

- Přístupový klíč a secret se berou z existujících
  `INITPAD_ARTIFACT_S3_ACCESS_KEY_ID` a `INITPAD_ARTIFACT_S3_SECRET_ACCESS_KEY`
  (gateway je dostane jako `AWS_ACCESS_KEY_ID` a `AWS_SECRET_ACCESS_KEY`).
  Anonymní přístup je po vzniku identity odmítnut.
- Privátní bucket vytváří `s3-init` přes `weed shell` ze stejného image, takže
  odpadá samostatný klientský image (`mc`).
- Gateway poslouchá na portu 9000 a síť má alias `minio`, takže starší `.env`
  s `http://minio:9000` dál platí.
- Volume `minio-data` je nahrazen `s3-data`; zálohy a obnova používají
  `s3-data.tar.gz`.

**Důsledky.** Data MinIO nejdou přečíst. Ověřené buildy jsou cache zdroje
pravdy, takže po přechodu se nasadí z nového buildu, ale starší artefakty pro
vrácení verze nejsou k dispozici. Starší zálohy `minio-data.tar.gz` se
neobnoví. Vestavěné úložiště zůstává jednoprocesové bez replikace, určené jen
pro lokální a důvěryhodné single-node použití; veřejná produkce dál používá
externí S3 (ADR-099). Dependabot sleduje nový image jako ostatní Compose
obrazy. Tento ADR nahrazuje výjimku pro MinIO v ADR-099.

**Testování.** Přes klienta `@aws-sdk/client-s3` z API proběhl HeadBucket,
put, head, get, presigned GET, delete a odmítnutí špatných i anonymních
údajů proti image připnutému v Compose.
