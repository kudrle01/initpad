# ADR-181 — Kdo přidá Agent server a jak dlouho práce na Agenta čeká

**Status:** Accepted

**Kontext.** Audit 13. 11. 2026 našel tři slepé uličky kolem Agenta:

1. Maintainer server typu Docker (Agent) přidal, ale Agenta připojit nesměl
   (enrollment vyžaduje workspace admina). Server zůstal navždy nepřipojený a
   UI neřeklo proč.
2. Job, jehož lease opakovaně vypršel (pád nebo zaseknutí Agenta), se
   pronajímal znovu a znovu. Protože fronta serveru je FIFO, zablokoval i
   všechny další joby.
3. Nasazení nebo odebrání na offline Agenta čekalo ve stavu „Waiting for Agent“
   bez limitu a bez rady.

**Rozhodnutí.**

- _Role._ Server typu Docker (Agent) smí vytvořit jen workspace owner nebo
  admin, tedy ti, kdo smí Agenta připojit. Maintainer dál přidá a ověří SFTP
  server a používá existující servery. API vrací 403 s textem
  `Only a workspace owner or admin can add a Docker Agent server, because only
they can connect its Agent. A maintainer can add an SFTP server or use
existing servers.` Web stejnou podmínku (`kind === 'docker'` a role není
  `owner`/`admin`) uplatní dřív, než maintainer formulář odešle.
- _Strop pokusů._ Job, jehož lease vypršel třikrát (`attempt >= 3`), při
  dalším pokusu o převzetí skončí `failed` s `resultCode =
attempts_exhausted` a vysvětlením. Navázaná operace, diagnostika, preflight
  nebo trasa brány se uzavře stejně jako u chyby hlášené Agentem a fronta
  pokračuje dalším jobem. Joby, které běží déle než jeden lease (`logs`),
  lease obnovují.
- _Offline Agent._ Agent je offline, když poslední heartbeat je starší než
  90 s (`ONLINE_AFTER_HEARTBEAT_MS`). Krátký výpadek do 10 minut (restart,
  self-update) jen varuje: job čeká ve frontě a stav prostředí i operace
  říká `Agent offline since <ISO čas>; start it or disconnect the server`.
  Delší výpadek, Agent, který se nikdy nepřipojil (`Agent has not connected
yet; start it or disconnect the server`), a každé odebrání se odmítnou
  hned stejnou hláškou. Odebrání tak nikdy nevisí.

**Důsledky.** Maintainer nevytvoří server, který nemůže použít. Zaseknutý job
blokuje frontu nejvýš tři lease (asi 90 s po posledním pádu). Uživatel u
offline Agenta hned vidí, co udělat. API hlášky zůstávají anglicky a web je
překládá přes katalog známých hlášek.
