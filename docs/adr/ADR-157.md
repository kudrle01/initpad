# ADR-157 — Veřejný SaaS nenasazuje na SFTP hosting dostupný jen přes školní VPN

**Status:** Accepted

**Kontext.** Část školního hostingu, typicky ESO, je dostupná přes SFTP pouze ze
školní VPN. SFTP spojení při nasazení navazuje control plane, nikoli Agent. Ve
veřejném SaaS smí control plane podle ADR-100 mířit jen na veřejně směrovatelné
adresy, takže takový server nelze přidat a žádné nastavení to nezmění.
Self-hosted edice tímto omezením netrpí: její hostitel VPN trasu má a SFTP
spojení vede z jeho sítě.

Zvažované možnosti:

- Připojit control plane do školní VPN. Odmítnuto. Sdílená veřejná služba by
  držela osobní školní přihlášení jednoho člověka a její kompromitace by
  otevřela přístup do interní sítě školy.
- Doplnit Agentovi úlohu, která SFTP nahrání provede zevnitř sítě. Agent drží
  jen odchozí spojení, takže model důvěry zůstává, ale vzniká nový typ úlohy
  s předáním SFTP credentials a připnutým host key. Odloženo jako možné budoucí
  rozšíření.
- Ponechat takové servery výhradně self-hosted edici. Zvoleno.

**Rozhodnutí.**

1. Veřejný SaaS nenasazuje na SFTP hosting, který je dostupný pouze přes školní
   VPN. Takové servery obsluhuje výhradně self-hosted edice, jejíž hostitel
   VPN trasu má.
2. Control plane SaaS se do školní VPN nepřipojuje a nedrží osobní školní
   přihlašovací údaje.
3. SFTP úloha prováděná Agentem zevnitř sítě je možné budoucí rozšíření a
   vyžaduje vlastní ADR.
4. Omezení se netýká Docker targetů za VPN nebo NATem. Agent navazuje jen
   odchozí spojení, health ověřuje lokálně a SaaS u Docker targetu privátní
   `publicUrl` přijímá.

**Důsledky.** Uživatel SaaS, který potřebuje ESO za VPN, musí použít
self-hosted edici nebo vlastní Docker server s Agentem. Omezení je uvedeno mezi
známými omezeními v `docs/RELEASE_READINESS.md` a v popisu edic v
`docs/ARCHITECTURE.md`. Hranice důvěry se nemění.

**Testování.** Chování pokrývají testy hosted egress politiky z ADR-100:
soukromý nebo smíšený DNS výsledek SFTP hosta je ve SaaS odmítnut před uložením.
Živě má Docker target za NATem potvrdit domácí Agent target stagingu.
