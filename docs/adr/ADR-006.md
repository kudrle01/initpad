# ADR-006 — Šifrování tokenů v DB (AES-256-GCM)

**Status:** Accepted

**Kontext.** Uložené Gitea tokeny jsou citlivé.

**Rozhodnutí.** Šifrovat `accessToken` v DB (formát `enc:v1:…`), klíč z env.
Dešifrování je odolné — při selhání (změněný klíč) vrátí prázdno místo pádu,
protože token je dnes jen fallback (git jede přes bota, viz ADR-002). Od
ADR-141 je nečitelná hodnota chyba, protože šifrování dnes chrání i hesla
serverů a secrety aplikací.

**Kompromis.** Změna `INITPAD_ENCRYPTION_KEY` znehodnotí dřív zašifrované
hodnoty. ADR-141 přidal výměnu klíče přes `INITPAD_ENCRYPTION_KEY_PREVIOUS`.
