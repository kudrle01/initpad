# ADR-174 — Lokální instalace publikuje porty aplikací i na host-gateway

**Status:** Accepted (upřesňuje ADR-173)

**Kontext.** Výchozí `INITPAD_DEPLOY_BIND_ADDRESS=127.0.0.1` drží přímé porty
aplikací vestavěného Docker cíle jen na hostiteli. Kontejnerové API je ale
ověřuje přes `host.docker.internal`, tedy přes adresu Docker host-gateway
(obvykle `docker0`, `172.17.0.1`). Port publikovaný jen na loopback odtud
dosažitelný není. Čistá instalace proto nemohla nasadit nic: ADR-173 nasazení
jen včas zastavil s radou nastavit `0.0.0.0`, což ale otevře porty do LAN.

**Rozhodnutí.**

1. Nová proměnná `INITPAD_DEPLOY_PROBE_BIND_ADDRESS` (IP nebo jméno). Když je
   bind loopback, `DockerProvider` publikuje port aplikace ještě na adrese,
   na kterou se toto jméno přeloží uvnitř API kontejneru. Compose ji nastaví
   na `host.docker.internal`, takže druhá vazba leží na host-gateway.
2. Docker zvolí volný port pro každou vazbu zvlášť. URL pro prohlížeč bere
   port z vazby na `INITPAD_DEPLOY_BIND_ADDRESS`, health sonda port z vazby na
   host-gateway. Totéž platí při `start` existujícího kontejneru.
3. Wildcard (`0.0.0.0`, `::`) jako sondovací adresa je odmítnut, loopback se
   ignoruje. Nepřeložitelné jméno ukončí nasazení srozumitelnou chybou dřív,
   než se sáhne na běžící kontejner.
4. `localDockerProbeBlockedReason` hlásí blokaci jen bez sondovací adresy, takže
   vestavěný cíl je po čisté instalaci znovu nabízen jako připravený.
5. Sítě prostředí, které API vytváří, nesou label `com.initpad.managed=true`,
   aby je `reset.sh` mohl spolehlivě odstranit.

**Důsledky.** `./install.sh` v režimu „jen tento počítač“ nasadí dev prostředí
bez ruční úpravy. Do LAN se nic neotevře: host-gateway je adresa bridge
rozhraní hostitele, ne LAN rozhraní. Kdo nastaví v démonu jiné
`host-gateway-ip`, určuje tím i tuto adresu. Instalace pro LAN přes IP
(ADR-175) dál nastavuje `0.0.0.0`, protože aplikace mají být dostupné z
ostatních počítačů.

**Testování.** Unit testy pokrývají dvojí vazbu portu, výběr portu podle
adresy, rozlišení sondovací adresy a label sítí. Živě: čistá instalace,
projekt `node-express`, CI a dev URL s odpovědí 200.
