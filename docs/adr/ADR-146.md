# ADR-146 — Podpis Supervisoru pokrývá metodu a cestu a produkce vyžaduje trvalé úložiště artefaktů

**Status:** Accepted

**Kontext.** Audit z 9. října 2026 našel dva nízké nálezy v provozních
hranicích platformy:

- HMAC podpis požadavků API na Supervisor (ADR-111) pokrýval čas, ID požadavku
  a hash těla, ale ne HTTP metodu a cestu. Podepsaný požadavek na
  `GET /v1/status` šlo během minutové platnosti poslat i na jiný endpoint se
  stejným tělem.
- API v produkci nastartovalo i bez S3 úložiště a artefakty pak drželo v paměti
  procesu. Restart je ztratil a paměť rostla bez omezení. SaaS edice úložiště
  vyžadovala, self-hosted ne.

**Rozhodnutí.**

1. Podpis v2 je HMAC-SHA256 nad řetězcem
   `v2\n<metoda>\n<cesta>\n<čas>\n<ID požadavku>\n<SHA-256 těla>` v hlavičce
   `x-initpad-signature-v2`. Supervisor přijímá jen v2.
2. API posílá navíc původní podpis v hlavičce `x-initpad-signature`. Platformní
   aktualizace vymění API dřív než Supervisor, takže nové API mezitím mluví se
   starým Supervisorem, který ověřuje jen v1. Podpis v1 se z API odstraní v
   releasu, po kterém už žádná podporovaná verze Supervisoru v1 neověřuje.
3. API s `NODE_ENV=production` bez nastaveného S3 bucketu a přístupových údajů
   odmítne start, v obou edicích. Úložiště v paměti zůstává pro vývoj a testy.
   Self-hosted compose profil úložiště nastavuje vždy (vestavěné MinIO).

**Důsledky.** Zachycený podepsaný požadavek už nejde použít na jiný endpoint
Supervisoru. Kombinace starého API s novým Supervisorem nefunguje; nevznikne
při aktualizaci přes Supervisor ani při instalaci releasu, jen při ručním
připnutí starého obrazu API. Produkční instalace, která běžela bez S3, po
aktualizaci nenastartuje, dokud úložiště nenastaví; dosud v ní nasazení po
každém restartu API ztrácela artefakty.

**Testování.** Testy Supervisoru ověřují přijetí podpisu v2, odmítnutí
podpisu statusu použitého pro update i odmítnutí samotného v1 přes skutečný
HTTP server. Test API klienta ověřuje oba podpisy. Test konfigurace ověřuje
odmítnutí produkce bez úložiště.
