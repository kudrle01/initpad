# ADR-168 — Certifikát platformy ke stažení v GUI a verze v postranním panelu

**Status:** Accepted

Doplňuje [ADR-161](./ADR-161.md) a [ADR-166](./ADR-166.md).

**Kontext.** Instalace s `tls internal` vydává certifikáty InitPadu i Gitey
z vlastní CA. Caddy nabízí její veřejný kořen na `/initpad-ca.crt` a API zná
otisk souboru pro instalační příkaz Agenta (ADR-161). Uživatel prohlížeče se
o souboru ale dozvěděl jen z výpisu instalátoru nebo z README, takže InitPad
i Gitea zůstávaly v prohlížeči nedůvěryhodné. Otisk z API navíc hashuje bajty
PEM souboru, kdežto prohlížeč a `openssl x509 -fingerprint` ukazují SHA-256
z DER podoby certifikátu; obě hodnoty nejde porovnat.

GUI také nikde neukazovalo běžící verzi platformy. Správce ji viděl jen na
kartě aktualizací a vývojář vůbec, i když ji potřebuje do hlášení chyby.

**Rozhodnutí.**

1. Metadata distribuce (`GET /api/agent/distribution`) vracejí u `privateCa`
   navíc `fingerprintSha256`, tedy SHA-256 z DER podoby prvního certifikátu.
   Původní `sha256` zůstává pro `sha256sum -c` v příkazu Agenta.
2. **Account settings** ukážou v self-hosted edici sekci **Platform
   certificate**, pokud instalace vlastní CA má. Sekce nabízí stažení ze
   stejného originu, otisk ve tvaru `AB:CD:…`, adresu přes HTTP pro počítač,
   který InitPadu ještě nedůvěřuje, a návod pro Windows, macOS a Firefox.
   Návod sdílí s certifikátem brány z ADR-166. Instalace s veřejným
   certifikátem sekci nemají.
3. `GET /api/auth/me` vrací `platformVersion`. Postranní panel ji ukazuje pod
   uživatelským menu jako `InitPad X.Y.Z`; správci vede na stránku
   **Platform** s aktualizacemi. Hodnota je jen pro přihlášené, anonymní
   endpointy verzi dál neprozrazují.

**Důsledky.** Jedna CA pokrývá jméno platformy i Gitey, takže jedna instalace
certifikátu stačí pro obě. Stažení přes HTTP lze v LAN podvrhnout; bezpečné je
díky otisku z HTTPS relace, stejně jako u brány. Starší API bez nových polí
GUI zvládne: otisk ani verzi pak neukáže.

**Testování.** Jednotkové testy pokrývají DER otisk proti parseru Node.js na
skutečném certifikátu, skrytí sekce bez vlastní CA a v SaaS edici, odkaz ke
stažení a zobrazení verze pro vývojáře i správce. Živě v prohlížeči proti
instalaci s `tls internal` zatím ověřeno nebylo.
