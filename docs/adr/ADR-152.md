# ADR-152 — PHP šablony běží na FrankenPHP

**Status:** Accepted

**Kontext.** Produkční obrazy šablon PHP, Laravel, Nette a Symfony spouštěly
vestavěný server PHP (`php -S`). PHP ho výslovně označuje jako vývojový
nástroj: obsluhuje jeden požadavek najednou a není určený pro provoz v síti.
Šablona `php` navíc měla front controller v kořeni projektu vedle
`Dockerfile` a `README.md`. Audit z 9. října 2026 to vedl jako střední nález.

**Rozhodnutí.**

1. Runtime fáze všech čtyř šablon vychází z oficiálního obrazu FrankenPHP
   (Caddy s vestavěným PHP) připnutého digestem. Fáze test a produkčních
   závislostí zůstávají na `php:8.3-cli-alpine` s Composerem.
2. Server poslouchá na portu 8080 (`SERVER_NAME=:8080`) a servíruje jen
   veřejný adresář (`SERVER_ROOT`): `public/` u PHP, Laravelu a Symfony,
   `www/` u Nette. Šablona `php` má front controller nově v
   `public/index.php`.
3. Kontejner běží jako `www-data`. Obraz odstraní z binárky FrankenPHP file
   capability `cap_net_bind_service`, kterou port 8080 nepotřebuje, takže
   server startuje i s odebranými capabilities a `no-new-privileges`, jak
   platforma aplikace spouští.
4. Admin API Caddy je vypnuté (`admin off`), aby kód aplikace nemohl měnit
   konfiguraci serveru přes `localhost:2019`. HEALTHCHECK obrazu proto místo
   admin API volá `/health` aplikace.
5. Produkční `php.ini` vypíná `expose_php` a zobrazení chyb, zapíná log chyb a
   nastavuje `variables_order = "EGPCS"`, aby frameworky četly proměnné
   prostředí.
6. Připnutá je verze 1.13.0, přestože vyšla 4. října 2026, tedy méně než dva
   týdny před touto změnou. Předchozí 1.12.7 obsahovala opravitelné HIGH a
   CRITICAL nálezy v Go závislostech, mezi nimi DoS v `net/http` při zpracování
   hlavičky Range, kterou souborový server Caddy používá a aplikace jsou
   dostupné z internetu.

**Důsledky.** Aplikace z PHP šablon obsluhují souběžné požadavky a mají
OPcache produkčního serveru. Soubory mimo veřejný adresář nejsou dostupné.
Nové projekty šablony `php` mají kód v `public/`; existující projekty se
nemění. Obraz FrankenPHP je větší než `php:8.3-cli-alpine`.

**Testování.** Akceptace šablony `php` (`scripts/test-template-images.sh`)
prošla. Laravel, Symfony a Nette byly ověřeny se závislostmi nainstalovanými
Composerem z git zdrojů, protože balíčky z GitHubu jsou v testovacím prostředí
blokované: obraz běžel jako `www-data` s odebranými capabilities a
`no-new-privileges`, `/health` vrátil 200, Docker HEALTHCHECK hlásil healthy,
`php tests/runtime-smoke.php` z CI šablon prošel, proměnné prostředí byly
vidět v `getenv`, `$_SERVER` i `$_ENV` a `composer.json` ani `../.env` server
nevrátil. Admin API Caddy neodpovídalo. Sken Trivy obrazu 1.13.0 nenašel
opravitelný HIGH ani CRITICAL nález. Plné sestavení všech fází proběhne v CI
(`container-images.yml`).
