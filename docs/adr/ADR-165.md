# ADR-165 — Instalátor Agenta postaví spravovanou bránu jedním příkazem

**Status:** Accepted

**Kontext.** ADR-164 popsal produkční bránu jako samostatné Compose nasazení.
Správce serveru s Agentem tak musel po příkazu z Manage Agent ještě sám zřídit
CA, TLS vstup a vnitřní bránu a předat Agentovi socket, kontejner a CA. Server
v režimu Spravovaná brána proto zůstával bez brány a kontrola končila
`Gateway TLS handshake failed`.

**Rozhodnutí.** Instalátor Agenta dostane `--gateway-domain DOMAIN`. Stejným
příkazem, bez Compose a bez dalších závislostí než Docker Engine, na místním
hostu spustí tři označené kontejnery (`com.initpad.gateway.installer=true`):
vnitřní CA `step-ca`, TLS vstup Caddy na 80/443 a vnitřní bránu s labelem
`com.initpad.gateway=true`. Instalátor sám nastaví `--gateway-container`,
`--gateway-admin-socket` a důvěru Agenta v kořen CA (svazek
`/etc/initpad-agent/trust-bundle.crt`, který případně obsahuje i CA samotného
InitPadu). Manage Agent pro server ve Spravované bráně přidá `--gateway-domain`
z veřejné URL; do příkazu se dostane jen ověřené DNS jméno, nikdy IP adresa.

- Kontejnery mají `read_only`, `cap_drop: ALL` (s `NET_BIND_SERVICE`, kterou
  vyžadují file capability binárek), `no-new-privileges` a limity zdrojů; image
  jsou připnuté digestem přímo v instalátoru. Jen vstup publikuje porty a žádný
  kontejner nedostane Docker socket.
- Certifikáty se vydávají přes ACME pro základní doménu při startu a pro
  aplikační jména při prvním použití; vstup se před vydáním ptá lokálního
  endpointu, který povolí jen jména v zóně. Platnost je sedm dní (výchozích 24
  hodin by činilo CA nepřetržitě nutnou).
- Opakované spuštění zachová CA a heslo a kontejnery nahradí aktuální
  definicí. Cizí kontejner stejného jména se nikdy nepřepíše.
- `--uninstall` bránu ponechá. Odstraní ji až `--remove-gateway` po výslovném
  potvrzení, protože smazání CA znamená, že klienti musí důvěřovat novému
  kořeni.

**Důsledky.** Server s Agentem je po jednom příkazu připravený, zbývá DNS
(`A` a wildcard `A` na server) a instalace kořene CA na klienty. CA žije na
jednom serveru; společnou CA pro víc serverů nahrazuje reference z ADR-164
(`--no-ca`). Brána je součástí instalátoru, takže se k serverům dostane s
novým releasem Agenta. Heslo CA a volume `initpad-gateway-ca-data` je potřeba
zálohovat. Instalátor vyžaduje volné porty 80 a 443.

**Testování.** Chování ověřeno proti skutečnému Dockeru: první instalace, opakované
spuštění (stejný kořen a heslo), odstranění (nezůstane kontejner, volume,
síť ani adresář), apex i aplikační jméno se ověří jen proti kořeni CA, cizí
jméno certifikát nedostane, platnost certifikátu je sedm dní. Testy kontrolují
validaci domény, hardening a pořadí kroků v instalátoru a generování příkazu v
Manage Agent. Ověření s reálným Agentem (**Test gateway**) provede správce.
