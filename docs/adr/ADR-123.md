# ADR-123 — Autentizační e-maily používají šifrovaný transakční outbox

**Status:** Accepted

**Kontext.** Ověřovací a aktivační odkazy bylo možné v self-hosted edici
zobrazit oprávněnému uživateli, ale reset zapomenutého hesla nebylo kam
doručit. Přímé volání SMTP uvnitř HTTP požadavku by zpomalovalo API a při
pádu mezi uložením tokenu a odesláním by odkaz ztratilo. In-memory fronta by
nepřežila restart a více API replik by mohlo stejnou zprávu odeslat současně.

**Rozhodnutí.** Token a `EmailOutbox` vzniknou v jedné PostgreSQL transakci.
Databáze uchovává pouze hash autentizačního tokenu; odkaz v outboxu je do
doručení šifrovaný pomocí stávajícího `INITPAD_ENCRYPTION_KEY`. Po úspěšném
odeslání se šifrovaný payload vymaže.

API worker vybírá zprávy krátkým databázovým lease. Atomický claim dovolí
provoz více replik; nedokončený lease se po timeoutu obnoví. Chyba SMTP vrátí
zprávu do fronty s exponenciálním backoffem a omezeným počtem pokusů.
Stabilní `Message-ID` omezuje duplicitu v případě pádu po přijetí zprávy
SMTP serverem, ale doručení je z principu at-least-once.

SMTP používá minimálně TLS 1.2, výchozí STARTTLS a omezené connection
timeouty. SaaS profil vyžaduje host, odesílatele, přihlašovací jméno a heslo
z read-only secret souboru. Self-hosted může SMTP vynechat; potom se vlastní
ověřovací a administrátorský aktivační odkaz nadále zobrazí jednou v UI.
Reset zapomenutého hesla bez SMTP zůstane neenumerující no-op a správce použije
reset s dočasným heslem.

**Proč.** Outbox spojuje vydání credentialu s trvalým delivery intentem bez
distribuované transakce mezi PostgreSQL a SMTP. Výpadek providera neblokuje
readiness ani přihlašování a tajný odkaz se nevrací do browseru, pokud je
e-mailové doručení zapnuté.

**Důsledky.** Provozovatel musí sledovat `mail.outbox.retry_scheduled` a
`mail.outbox.failed`; centrální metriky a alerting jsou samostatný observability
gate. Před veřejným provozem je stále nutné ověřit konkrétní SMTP provider,
doručitelnost a rotaci hesla. Obecné notifikace a marketingové e-maily nejsou
součástí tohoto outboxu.

**Testování.** Testy ověřují, že se plaintext odkazu neukládá, úspěšné
odeslání payload smaže, dočasná chyba naplánuje retry a prohraný lease
neodešle duplikát. Regrese auth vrstvy kontroluje atomické zařazení resetu a
deployment testy file-backed SMTP secret.
